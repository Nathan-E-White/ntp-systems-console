01 / Claim Boundary

What This Model Is

The default profile is a Pewee-scale benchmark closure connected to a bounded one-dimensional representative channel and an ideal frozen-hydrogen nozzle calculation. It is not a Pewee reconstruction, NESS replacement, qualified fuel model, transient solver, safety analysis, or prediction of delivered hardware performance.

Conservative conclusion rule. The application cannot report an unqualified nominal posture while a controlling basis is missing, outside a correlation range, or dependent on a screening closure.

04 / Representative Channel

ELM-Style Axial March

The channel is divided into 36 axial control volumes. Deposited power is normalized from ELM's Pewee power-shape polynomial. Each station advances enthalpy, iterates wall temperature, and accumulates friction, acceleration, entrance, and exit losses.

Pewee axial power shape

PSF(ξ)=A+Bξ+Cξ2+Dξ3+Eξ4

ξ = x/L, bounded 0-1

A-E = 0.315263743551, 4.01075764283, -2.81198488737, -2.13642616902, 0.653731955838

Energy and wall temperature

ηP=m˙[h(Tout)−h(Tin)]q=hcAs(Twall−Tbulk)

η = calibrated or user-supplied coupling efficiency

hc = Nu k/Dh

q = station heat rate

As = wetted heat-transfer area

Modified Wolf-McCarthy and Taylor correlations

Nu=0.025Re0.8Pr0.4TwTb−0.551+0.3xD−0.7f=0.0014+0.125Rew0.32TbTw

Nu = Nusselt number

Rew = wall-referenced Reynolds number

Pr = Prandtl number

f = Fanning friction factor

ELM documents the Taylor turbulent range at approximately 3,000 < Rew < 187,000. The app records station-level warnings outside encoded ranges. Default geometry is labeled representative NERVA-family geometry: 1.3716 m length, 2.54 mm hydraulic diameter, and 7,638 channels. It is not asserted as Pewee hardware geometry.

05 / Nozzle and Performance

Ideal Frozen-Hydrogen Performance

Area ratio, exit state, and thrust

AeAt=1Me2γ+11+γ−12Me2γ+12γ−1F=m˙Ve+(pe−pa)Ae

Me = supersonic exit Mach number

γ = temperature-dependent ideal-gas heat-capacity ratio

Ve = ideal exit velocity multiplied by √ηn

ηn = cited or user-supplied lumped nozzle performance factor

NASA CEA is identified as the higher-fidelity replacement for equilibrium/frozen chemistry and dissociation. The browser does not implement CEA.

06 / Review Flags

No Synthetic Stability Score

The compatibility field formerly named stabilityScore now carries model-basis completeness: 100% complete, 70% screening closures active, or 0% incomplete. The visible UI labels it accordingly. The review posture is:

limit   when channel wall criterion margin < 0 K
nominal only when no missing or screening basis remains
watch   otherwise

Separate flags identify thermal criterion exceedance, incomplete pressure basis, out-of-range correlations, power-to-flow mismatch, unavailable transient model, and user overrides.
